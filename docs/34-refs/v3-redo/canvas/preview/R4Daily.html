Four new things here, each built from parts you already use: ⌘D and a ★ in the address line; the Field gains bookmark and history groups and a scoped view (no bookmarks window or bar); one import sheet; a sign-ins choice on a space; the footer gets downloads and extensions popovers.
1a · ⌘D bookmarks the page⌘D (or the Field command “Bookmark this page”) saves it and opens this popover under the address line: name, folder, Remove, Done. ↩ or a click away keeps it. The address line keeps a filled ★ while the page is bookmarked; ⌘D again opens the same popover. Folders are the ones you import from Chrome plus “Bookmarks bar” and “Other”; there is no bookmarks bar drawn anywhere.

1c · Bookmarks, browsed in the FieldThe Bookmarks command (or ⇥ on the Bookmarks group) scopes the Field: the scope pill, folders first, then recently added. ↩ on a folder opens it in place, ⌫ on an empty query goes up. Typing filters inside the scope. History has the same scoped view (days as headings, “Clear history…” as its last row). No separate bookmarks window or page.
