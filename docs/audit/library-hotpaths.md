# Audit — library-hotpaths (agentic-ui `login-methods`, frame-rendered code only)

Read-only audit of what the harness renders each frame: `crates/aui/src/transcript/*`,
`nav/*`, `composer/*`, `screens/login.rs`, the `data/*` they use, and `aui-motion`.
No source file in either repo was changed. Format follows `docs/briefs/muse-audit-review.md` §"What a finding looks like".
Paths below are relative to `/Users/latekaapi/Projects/agentic-ui` unless marked `harness:`.

Method: read the render (`RenderOnce::render`) path of every listed component; every
claim cites code read in this session. gpui-kit/gpui-pre internals were not inspected —
anything delegated there is marked unverified rather than assumed.

Context the brief already establishes (not re-derived, built on): the transcript is a
virtualised list over `Rc<Vec<Turn>>` (off-screen turns do not render); `Markdown`
parses are memoised in `parsed_markdown`; `prose()` re-parses every render; the
sidebar builds every row every frame.

## Findings

- **[library-hotpaths-1] `prose()` re-parses its markdown on every render with no memo cache** — `crates/aui/src/transcript/prose.rs:177` — medium — `prose()` calls the module-local `parse(markdown)` on each frame, allocating `Block`/`Span`/`String`s linearly in the source, while the sibling `markdown()` goes through the `Arc`-cached `parsed_markdown` (`crates/aui/src/transcript/markdown.rs:954`); every plan item re-parses per frame (`crates/aui/src/transcript/plan.rs:150`) and so does every question preview (`crates/aui/src/transcript/question.rs:278`) — back `prose()` with `parsed_markdown` (or an equivalent `Arc` cache) so repeated renders of unchanged text hit shared blocks.
- **[library-hotpaths-2] `CodeBlock` re-tokenizes every visible line on every frame** — `crates/aui/src/transcript/code.rs:284` — medium — the render loop calls `syntax_runs_in(line, …)` per line per frame with no cache, so a tall visible code block re-runs the tokenizer over its whole text each frame; the tokenizer itself is allocation-per-line (`crates/aui/src/transcript/syntax.rs:40`) — memoize runs per `(language, line)` (bounded cache like `PARSED_CACHE_CAP`) or per block revision.
- **[library-hotpaths-3] Shell tool output re-parses ANSI on every line on every frame** — `crates/aui/src/transcript/tool_card.rs:257` — medium — `shell_body` runs `parse_ansi(line)` + `ansi_runs(…)` per shown line per frame with no cache, plus a fallback rebuilt-`TextRun` allocation when lengths mismatch; long `userShell` output re-parses in full each frame — cache the parsed `(text, runs)` per output revision (or pre-parse once where the `ToolBody` is built).
- **[library-hotpaths-4] Streaming caret re-shapes the closing block every frame** — `crates/aui/src/transcript/turns.rs:486` — medium — while `streaming`, each frame runs `last_block_runs` (cache-backed parse, cheap) *and* `window.text_system().shape_text(…)` over the closing block at the measured wrap width (`turns.rs:402`), i.e. a full text-shaping pass per frame per streaming turn — cache the measured trailing width keyed on `(source hash, wrap width)` and re-shape only when either changes.
- **[library-hotpaths-5] `span_runs` rebuilds text, runs and link ranges per block per frame, including `font()` lookups** — `crates/aui/src/transcript/markdown.rs:976` — medium — the parse cache stops at `Block`s; every frame still concatenates a fresh `String`, builds a fresh `Vec<TextRun>`/`Vec<LinkRange>`, and calls `font(scale::FONT_UI)` / `font(scale::FONT_MONO)` per block (`markdown.rs:981-982`; same pattern in `prose.rs:135-136` `runs()`) — hoist the two `Font` handles to `LazyLock` statics and, if profiling justifies it, cache runs per `(block hash, style hash)`.
- **[library-hotpaths-6] `parsed_markdown` cache hits still cost a full-source hash plus a global lock per turn per frame, and streaming churn defeats it** — `crates/aui/src/transcript/markdown.rs:954` — medium — each render hashes the whole source (`hash_source`) plus 16 style floats, then locks a process-wide `Mutex<HashMap>`; a streaming turn's source changes per chunk so it *never* hits, and past 128 entries the cache `clear()`s everything, evicting settled turns' entries so they re-parse too — shard or generation-key the cache per turn (harness turn id is stable across chunks) instead of hashing full sources, and replace evict-all with per-turn replacement.
- **[library-hotpaths-7] `format!` element ids allocated per block, line and row on every frame** — `crates/aui/src/transcript/markdown.rs:1244` — medium — `block_id` formats `md-{index}-{name}` per block per frame, plus per-item `format!("li{n}")` (`markdown.rs:1328,1342`), per-cell `format!("h{n}"/"c{r}-{n}")` (`markdown.rs:1390,1410`), per-line `format!("sel-{i}")` (`code.rs:290`), per-row `format!("child-{i}")` (`nav/session_row.rs:456,626`), `format!("sugg-{i}")`/`format!("q-{}")` (`composer/queue.rs:167,275`), `format!("row-{index}")` (`composer/pickers.rs:219,252`), `format!("chip-x-{}")`/`format!("chip-{}")` (`composer/composer.rs:395,411,420`) — key by integer child ids via the existing `aui_motion::child_id` helper (`crates/aui-motion/src/lib.rs`) instead of formatted strings.
- **[library-hotpaths-8] By-value component APIs force the harness to clone whole payloads every frame** — `crates/aui/src/transcript/tool_group.rs:81` — medium — `tool_group(group: ToolGroupData, …)`, `question_card(prompt, options: Vec<QuestionOption>)` (`question.rs:119`) and `plan_card(items: Vec<String>)` (`plan.rs:57`, which then re-maps to `SharedString` per construction at `plan.rs:57-63`) all take owned payloads, so the harness clones per render — e.g. `data.clone()` on every frame (`harness:crates/harness/src/transcript.rs:470`) — take `&ToolGroupData` / `&[QuestionOption]` / `&[SharedString]` (storing `SharedString` clones, which are cheap) instead.
- **[library-hotpaths-9] `SelectableText::build_styled` clones the full text and run vec on every frame** — `crates/aui/src/transcript/selectable.rs:405` — medium — `StyledText::new(self.text.clone()).with_runs(self.runs.clone())` (`selectable.rs:416-424`) duplicates the cell's entire shaped text plus runs per frame, scaling with cell size on top of finding 5 — build the styled text from a shared (`Arc`/`SharedString`) buffer or cache it per `(text revision, runs revision)`.
- **[library-hotpaths-10] Browser tool body runs an infinite pulse loop while visible, even when settled** — `crates/aui/src/transcript/tool_card.rs:337` — medium — `browser_body` calls `looping(…, Infinite, …)` unconditionally, and `looping` requests a frame on every render while mounted (`crates/aui-motion/src/looping.rs` docs), so any visible browser screenshot placeholder holds the frame loop open forever doing a decorative ring pulse — gate the ring on a pending/recent-capture state and render the settled placeholder statically.
- **[library-hotpaths-11] Turn selection takes `Option<TextSelection>` by value while `Markdown::selection` borrows** — `crates/aui/src/transcript/turns.rs:181` — low — `UserTurn::selection` (`turns.rs:181`) and `AssistantTurn::selection` (`turns.rs:385`) force the caller to clone the selection per frame where the inner `Markdown::selection(Option<&TextSelection>)` (`markdown.rs:1530`) already shows the borrow form works — change both turn setters to `Option<&TextSelection>` for API consistency and zero per-frame clone.
- **[library-hotpaths-12] Small bounded per-frame string formats in footers, meters and labels** — `crates/aui/src/transcript/turns.rs:421` — low — `footer_items` formats model/duration/tokens/cost strings per turn per frame (`turns.rs:421-438`), `format_duration` formats per tool card per frame (`tool_card.rs:128-130`), `meter`/`context_meter` format `"{}%"` per frame (`data/meter.rs:51`, `data/context_meter.rs:99-100`), the login headline formats `"Sign in to {}"` per frame (`screens/login.rs:242-244`), the queue header formats per frame (`composer/queue.rs:272`) — each is small and bounded, but they are pure per-frame garbage; hoist to the data owners (format on state change, store `SharedString`).
- **[library-hotpaths-13] Dead code in the prose module: `_unused` stub and caller-less `last_paragraph_runs`** — `crates/aui/src/transcript/prose.rs:209` — low — `fn _unused` (`prose.rs:209-210`, `#[allow(dead_code)]`) is a stable-type placeholder with no purpose, and `last_paragraph_runs` (`prose.rs:169`, a thin wrapper over `last_block_runs`) has no non-test callers in either repo (only its re-export in `transcript/mod.rs:30` and its own tests) — delete `_unused` and either delete `last_paragraph_runs` or document why the alias is kept.
- **[library-hotpaths-14] `markdown_selected_text` bypasses the parse cache** — `crates/aui/src/transcript/markdown.rs:1581` — low — the copy path calls uncached `parse_markdown(source)` instead of `parsed_markdown`, so every ⌘C over a turn re-parses the full source (copy is off the frame path, hence low, but the cached one-liner is free) — call `parsed_markdown(source, …)` / `selected_text_in_blocks` like `Markdown::selected_text` does (`markdown.rs:1550-1553`).
- **[library-hotpaths-15] Settled springs/tweens/presence stop-requesting-frames behaviour is unverified; infinite loops are by design** — `crates/aui-motion/src/looping.rs:47` — low — `spring`/`tween`/`presence` all delegate settling to gpui-kit base (`spring.rs`, `tween.rs`, `presence.rs:53-60`), whose settled-frame behaviour was not inspected in this audit (gpui-kit source out of scope), while `looping` documents that it requests a frame every render for as long as it is mounted — mounted-while-idle loopers found: finding 10 (browser ring); correctly gated: `pulse_ring` on `active` (`pulse.rs`), spinner only where working state mounts it (`tool_card.rs:149`, `tool_group.rs:125`, `status.rs:203`, `activity.rs:102`, `approval.rs:483`), caret only while `streaming` (`turns.rs:479`), braille only under `StatusLead::Braille` (`status.rs:205`) — verify settled silence with `HARNESS_FRAME_STATS=1` on an idle window and fix any primitive that keeps requesting frames at rest.
